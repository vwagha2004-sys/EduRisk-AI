# EduRisk AI — Academic Performance & Risk Prediction System

EduRisk AI is a machine learning-based academic analytics system designed to analyze student performance, predict academic outcomes, and identify students who may be at academic risk.
The project combines machine learning techniques with an interactive Streamlit dashboard to provide data-driven insights into student academic performance.

## 🎯 Project Objective
The main objective of EduRisk AI is to use academic data to:

* Analyze student performance patterns.
* Predict academic performance using machine learning.
* Identify students who may be at academic risk.
* Visualize academic performance through an interactive dashboard.
* Provide data-driven academic insights.

## 🚀 Key Features

* Academic performance prediction using **XGBoost**.
* Academic risk identification.
* Feature engineering for improved model input.
* **SMOTE** for handling class imbalance.
* **PCA** for dimensionality reduction.
* Interactive **Streamlit dashboard**.
* Academic performance visualization and insights.

## 🧠 Machine Learning Approach

The project follows these major steps:

1. Data loading and preprocessing.
2. Exploratory Data Analysis (EDA).
3. Feature engineering.
4. Handling class imbalance using SMOTE.
5. Dimensionality reduction using PCA.
6. Model training using XGBoost.
7. Model evaluation.
8. Student performance and risk prediction.
9. Visualization through the Streamlit dashboard.

## 📊 Model Performance

The XGBoost model achieved an **R² score of 0.89** during model evaluation.

> Model performance may vary depending on the dataset and evaluation conditions.
